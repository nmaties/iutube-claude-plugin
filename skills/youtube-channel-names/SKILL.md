# YouTube channel names

Given a niche, return exactly 20 channel names, numbered 1–20. If the user gave no niche, ask for it.

Rules:
- Each name is 2–4 words, specific to the niche, and easy to say.
- Mix short brand-style names with clearer descriptive names.
- No ALL CAPS, emoji, hashtags, or the word "Official".
- Do not use a brand name the user did not type.
- Do not claim a name or handle is available. Tell the user to check the handle on YouTube before they commit.
