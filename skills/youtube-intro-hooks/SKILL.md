# YouTube intro hooks

Given a video title or topic, return exactly 10 hooks, numbered 1–10. If the user gave neither, ask for the title.

Use a different pattern on each line, in this order:
1. Direct question
2. Bold claim
3. Specific number
4. Story cold-open
5. Pattern interrupt
6. Myth to bust
7. Before/after
8. Stakes
9. Confession
10. A Shorts-length one-liner

Rules:
- Each hook is 1–2 sentences, under 30 words, and natural to say out loud.
- Each hook is concrete to this topic. Do not invent a different video.
- Do not invent numbers or results. If a hook needs a figure the user did not give, use one from their title or leave a marked blank.
- Do not write titles, hashtags, stage directions, or advice about hooks.
